#	长图模式

[中文首页](../README.md) · [Agent入口](../AGENTS.md) · [卡片模板格式](card-template-format.md) · [小红书卡片](xhs-cards.md)

长图是一张很长的竖图（宽1080或1440，高几千到一万多像素），适合活动回顾、发布图解这类内容。内容仍然写在 Markdown里；模板只负责版式，不提供填格子的编辑界面，也不做自由画布。

##	1.	怎么用

1.	在顶栏切到「长图」（手机宽度下在模式下拉里选）。
2.	照常写 Markdown。第一个一级标题、紧跟它的一段短文字和第一张图会变成头部；二级标题开启小节；连着放的图片自动排成照片组；最后一个单独一行的 `---`之后是落款。
3.	在右栏「模板」里选模板、变体（模板有多个变体时才出现）、宽度和格式。选择存在本机 `mopai.long-options.v1`，刷新后还在。
4.	点顶栏的「导出长图」。导出时可以取消；读图失败会列出地址并暂停导出；超过浏览器 canvas上限时会分成几张，文件名带 `1of3`这样的序号并打成 ZIP，界面会明说分成了几张。

预览区按可用宽度等比缩小整张长图，上下滚动查看；改稿后后台重排，滚动位置不跳。空稿、只有标题、没有图片、没有二级标题都会得到一个合理的样子，不会报错。

##	2.	Markdown对应规则

| Markdown里写的 |长图里变成 |
|---|---|
|第一个一级标题 |头部的大标题 |
|紧跟一级标题、不超过60字的一段 |副标题（和卡片规则一致） |
|一级标题之后、第一个二级标题之前出现的第一张图 |头图；没有就是无头图的头部 |
|二级标题 |一个小节的开头（标签） |
|小节里的段落、列表、引用、表格、代码、三级标题 |正文；复用卡片正文的节点生成 |
|连着放的几张图（中间没有别的内容） |一个照片组 |
|最后一个单独一行的 `---`之后的内容 |落款（居中） |
|其余的 `---` |小节之间的分隔，模板决定画不画 |
| front matter的 `author` |落款处可用的作者名 slot；`cover`、`titles`不读 |

图片的 alt文字不显示，和公众号里的行为一致。多图块（`gallery` / `carousel`）的第一张可以当头图，其余进入照片组。

###	照片组

照片保持原比例，默认不裁；一行里的照片等高，一行排满内容宽度。分行规则：

-	1张 →一行一张；
-	偶数张 →两张一行；
-	奇数张（≥3）→第一张单独一行，其余两张一行。

因此「1大 +2×2」「2×2」「2×3」「单张」都能自然得到。同一组里一横一竖也会照样等高，宽度按比例分，不会裁切。引擎在图片解码后测量原始尺寸、算出每张的显示宽高并冻结成内联样式，模板只负责外框、间距和装饰。

##	3.	模板

长图模板沿用 `.reedcard`（zip + `manifest.json`），只是在 manifest里写 `"kind": "long"`；不写就是原来的卡片。现有的卡片模板文件一个字都不用改，`formatVersion`也不变。因为文件格式相同，上传、本机存储、云端同步、HTML/CSS安全检查全部复用卡片那条路径。

字段、两个页面片段（`header` / `footer`）、slot、条件属性、引擎生成的 class表、照片组结构和最小示例，见 [卡片模板格式](card-template-format.md#9-长图模板-kind-long)。仓库里的完整例子是 [`examples/card-templates/example-long/`](../examples/card-templates/example-long/)。

应用里按 `kind`分组：卡片模式的模板列表只出卡片模板，长图模式只出长图模板。把长图模板拖进卡片的「上传」也能收下，只是它出现在长图那边；反过来一样，上传后会有一句提示说明它去了哪边。云端接口不改，服务端不解压。

CSS作用域根是 `.reed-long-root`，`position: fixed` / `sticky`、脚本、内联事件、包外资源和其它现有禁令一条不放松。

##	4.	导出

-	输出一张图，宽1080或1440，高度由内容决定，文件名用文章标题。JPG质量0.92，PNG不压。
-	照片先缩再嵌：按它在长图里显示的像素宽度 ×导出倍率重采样，不放大；一张一张顺序解码，避免三十张原图同时进内存。预览用的也是重采样后的图。
-	断行和预览一致：复用卡片的精确字号（`markExactFontSizes`）和 `cardFontCss`，只嵌用到的字体切片 /包内字体。
-	很高的图：一次把一万多像素高的 DOM画进一张 canvas可能失败或极慢。导出先测量，能整张放下就整张画；放不下就在模块边界（头部、小节、小节内的块、照片行）切段，逐段画到一张 canvas上再拼。整条渐变背景由同一份 CSS背景按绝对位置裁切，拼接处不重新起渐变。
-	超过浏览器上限：运行时探测当前浏览器的单边和总面积上限（不写死数字），超了就按模块边界分成几张，文件名带 `1of3`序号并打成 ZIP，界面明说「这张图太长，分成了 N张」。不会把几张假装成一张，也不会悄悄缩小。
-	读图失败：列出读不到的地址，暂停导出，保留预览里能显示的图；修好链接后点「重试」。预览不会再因为一张跨域 /被 CSP拦住的图永远停在「排版中」。

##	5.	界面与状态

- `EditorMode`新增 `'long'`；顶栏和手机模式下拉都可选。动效仍是原地切换，不受影响。
-	右栏「模板」复用卡片面板的结构：「我的 /公用」两组、上传、管理、同步状态。长图公用模板和卡片公用模板走同一个 zip加载器，只是 `kind`不同。
-	宽度1080 /1440，默认1080；格式 JPG / PNG，默认 JPG。
-	顶栏主按钮在长图模式下是「导出长图」；导出中显示进度、可取消。
-	界面使用现有 `ya-well` / `ya-selected`和按钮 token，浅色深色、中文英文都可用。

##	6.	第一套公用模板「蓝色科技活动回顾」

版式参考：作者本人的一张活动回顾长图（未公开）。仓库里只有还原后的模板源文件，没有她的照片、活动名称、单位名称或文案。

-	背景是一整条亮蓝到海军蓝的 CSS渐变。
-	头图顶满宽度，底部渐隐；标题是 Noto Sans SC700，白色到浅蓝的渐变字并向右倾斜；副标题同样处理。没有头图时头部是一块渐变加标题。
-	小节标签：`»»`、白底标签框、框顶蓝色短条、Zhuque Fangsong的宽字距蓝色文字；下面一行说明、一条渐隐细线；照片组在细描边外框里，框下有一个小 v箭头指向下一节。
-	落款：居中口号，Zhuque Fangsong、宽字距、白色；作者 slot在下面。
-	原图里那两行字距很宽的英文小字是她后来明确不要的装饰，模板不做；用户自己在正文里写英文，照正文排。
-	头图里的蓝天合成是用户在外部做好的，模板不负责合成。
-	标签框顶上的蓝色短条是照原图做的，去留等她定。

私有楷体变体（不进仓库）把标签和落款换成霞鹜文楷，用于对比样张；字体文件按8105字 +常用标点 + ASCII裁成 woff2，超过4 MB时按 `unicodeRange`拆成多条字体记录。
