# 长图模式

[中文首页](../README.md) · [Agent 入口](../AGENTS.md) · [卡片模板格式](card-template-format.md) · [小红书卡片](xhs-cards.md)

长图是一张很长的竖图（宽 1080 或 1440，高几千到一万多像素），适合活动回顾、发布图解这类内容。内容仍然写在 Markdown 里；模板只负责版式，不提供填格子的编辑界面，也不做自由画布。

## 1. 怎么用

1. 在顶栏切到「长图」（手机宽度下在模式下拉里选）。
2. 照常写 Markdown。第一个一级标题、紧跟它的一段短文字和第一张图会变成头部；二级标题开启小节；连着放的图片自动排成照片组；最后一个单独一行的 `---` 之后是落款。
3. 在右栏「模板」里选模板、变体（模板有多个变体时才出现）、宽度和格式。选择存在本机 `mopai.long-options.v1`，刷新后还在。
4. 点顶栏的「导出长图」。导出时可以取消；读图失败会列出地址并暂停导出；超过浏览器 canvas 上限时会分成几张，文件名带 `1of3` 这样的序号并打成 ZIP，界面会明说分成了几张。

预览区按可用宽度等比缩小整张长图，上下滚动查看。空稿、只有标题、没有图片、没有二级标题都会得到一个合理的样子，不会报错。

## 2. Markdown 对应规则

| Markdown 里写的 | 长图里变成 |
|---|---|
| 第一个一级标题 | 头部的大标题 |
| 紧跟一级标题、不超过 60 字的一段 | 副标题（和卡片规则一致） |
| 一级标题之后、第一个二级标题之前出现的第一张图 | 头图；没有就是无头图的头部 |
| 二级标题 | 一个小节的开头（标签） |
| 二级标题下面紧跟的第一段 | 这一节的说明（`.reed-long-lede`） |
| 小节里的段落、列表、引用、表格、代码、三级标题 | 正文 |
| 连着放的几张图（中间没有别的内容，一行放几张也行） | 一个照片组；图片语法和正文完全一致（带标题、尖括号地址都认），代码块和注释里的图片示例不算照片 |
| 最后一个单独一行的 `---` 之后的内容 | 落款 |
| 其余的 `---` | 小节之间的分隔，模板决定画不画 |
| front matter 的 `author` | 落款处可用的作者名 slot；`cover`、`titles` 不读 |

图片的说明文字（`![说明](…)` 方括号里的字）是否显示由模板决定：支持照片说明的模板把它排在照片下方，其余模板不显示。另外，以加粗词开头的段落（`**导语** …`）、整段加粗的短句（`**要点**`）和每项都以加粗开头的列表（`- **10倍** 推理速度提升`），模板可以排成标签、数字卡片或步骤卡，写法见 [卡片模板格式](card-template-format.md#引擎生成的结构)。多图块（`gallery` / `carousel`）的第一张可以当头图，其余进入照片组。

### 照片组

照片保持原比例，不裁；一行里的照片等高，一行排满内容宽度。分行规则：

- 1 张 → 一行一张；
- 偶数张 → 两张一行；
- 奇数张（≥ 3）→ 第一张单独一行，其余两张一行。

因此「1 大 + 2×2」「2×2」「2×3」「单张」都能自然得到。同一行里一横一竖也照样等高，宽度按比例分。引擎在图片解码后量出原始尺寸，算出每张的显示宽高并写成内联样式，模板只负责外框、间距和装饰。

## 3. 模板

长图模板沿用 `.reedcard`（zip + `manifest.json`），只是在 manifest 里写 `"kind": "long"`；不写就是原来的卡片。现有的卡片模板文件不用改，`formatVersion` 也不变。因为文件格式相同，上传、本机存储、云端同步、HTML / CSS 安全检查全部复用卡片那条路径。

字段、两个页面片段（`header` / `footer`）、slot、条件属性、引擎生成的 class 和最小示例，见 [卡片模板格式 · 长图模板](card-template-format.md#10-长图模板)。模板可以用 `customize` 开放几个颜色和字体给读者在右栏改，规则和卡片相同，见 [customize](card-template-format.md#customize)；改动写在 `.reed-long-root` 和 `.reed-long-flow` 上，导出时字体一并内嵌。仓库里的完整例子是 [`examples/card-templates/example-long/`](../examples/card-templates/example-long/)。

应用里按 `kind` 分组：卡片模式的模板列表只出卡片模板，长图模式只出长图模板。把长图模板拖进卡片的「上传」也能收下，只是它出现在长图那边，上传后会有一句提示说明它去了哪边；反过来一样。云端接口不改，服务端不解压。

CSS 的作用域根是 `.reed-long-root`；`position: fixed` / `sticky`、脚本、内联事件、包外资源和其它现有禁令一条不放松。

## 4. 导出

- 输出一张图，宽 1080 或 1440，高度由内容决定，文件名用稿件名。JPG 质量 0.92，PNG 无损。
- 照片先缩再嵌：按它在长图里显示的像素宽度 × 导出倍率重采样，不放大；一张一张顺序解码，避免几十张原图同时进内存。
- 断行和预览一致：复用卡片的精确字号（`markExactFontSizes`）和 `cardFontCss`，只嵌用到的字体切片和包内字体。精确字号补丁与卡片导出共用同一份，卡片与长图重叠导出时互不干扰，全部结束后原型严格还原。
- 浏览器上限：运行时探测当前浏览器 canvas 的单边和总面积上限（不写死数字）。整张放得下就一次画完；放不下就在模块边界（头部、小节、小节内的块、照片行）切开，分成几张，文件名带 `1of3` 序号并打成 ZIP，界面明说「这张图太长，分成了 N 张」。不会把几张假装成一张，也不会悄悄缩小。
- 读图失败：列出读不到的地址并暂停导出，预览里能显示的图照常显示；修好链接后点「重试」。生产环境的 CSP 只放行本站、`https:` 和配置的图床，别处的 `http:` 图片会落进这一条。

## 5. 界面与状态

- `EditorMode` 新增 `'long'`；顶栏和手机模式下拉都可选。
- 右栏「模板」复用卡片面板的结构：「我的 / 公用」两组、上传、管理、同步状态。长图公用模板和卡片公用模板走同一个加载器，只是 `kind` 不同。加载失败时同一行提供「重试」，重试只重新请求当前 kind 的公用包，成功后就地补全，不需要刷新页面。
- 宽度 1080 / 1440，默认 1080；格式 JPG / PNG，默认 JPG。
- 顶栏主按钮在长图模式下是「导出长图」；导出中显示进度、可取消。
- 公式和 Mermaid 图表没就绪时同样暂停导出：卡片与长图共用一份就绪事实，失败时写明原因并给出重试；`data-long-math`、`data-long-diagram` 与 `[data-graphics-warning]` 供验收脚本读取状态。
- 预览根节点 `[data-long-view]` 带 `data-long-layout`（`pending` / `ready` / `empty` / `error`）和 `data-long-export-blocked`，供验收脚本判断状态。

## 6. 公用模板「蓝色科技活动回顾」

源文件在 [`card-templates/public/blue-tech-recap/`](../card-templates/public/blue-tech-recap/)，构建时由 `npm run pack:public-cards` 打成 `public/card-templates/blue-tech-recap.reedcard`。

- 背景是一整条亮蓝到深蓝的 CSS 渐变。
- 头部：标题和副标题站在渐变上，Noto Sans SC 700、白到浅蓝的渐变字、向右倾斜；头图接在标题下面，上沿渐显、下沿渐隐。标题字号随长度缩小（见模板格式里的 `--long-title-units`），太长才换行。没有头图时头部是一块带网格的渐变加标题。
- 小节：`»»`、白底标签框（朱雀仿宋、宽字距、蓝字）、一行说明、一条渐隐细线；照片组在细描边外框里，框下有一个小箭头指向下一节。
- 落款：居中一句话，朱雀仿宋、宽字距、白色；作者 slot 在下面。

## 7. 验证

```bash
npm run check
npm test -- --maxWorkers=2
npm run build
node scripts/cdp-verify-long-image.mjs 3295 9405
```

浏览器验收用中性测试稿（5 节、24 张占位照片、一横一竖混排、列表和引用、有落款），覆盖 1080 / 1440 的 JPG / PNG、预览与导出的分段像素对比、标题和小节标签的墨色、渐变接缝、实际渲染字体、强制小上限时的分张 ZIP、空稿 / 只有标题 / 没有图 / 读图失败，以及上传示例模板、刷新后仍在、删除回默认、浅色深色和中英文界面。输出在 `verify-out/long/<时间戳>/`。
